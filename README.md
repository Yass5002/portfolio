# Yassine El Ouazzani Portfolio

> The personal portfolio and digital resume of Yassine El Ouazzani.

This repository contains the source code for my professional portfolio website, showcasing my skills as a Mobile App and Full Stack Developer. It highlights my featured projects, educational background, technical stack, and provides multiple contact avenues.

## Live Website

You can view the live portfolio here [yssn.tech](https://yssn.tech/)

## Features

*   **Responsive Design** Built with a mobile first approach using vanilla CSS3.
*   **Dynamic Data Fetching** Automatically pulls and parses project counts and technology usage directly from the GitHub REST API.
*   **SEO Optimized** Implements advanced meta tags, OpenGraph protocol for social sharing, and structured JSON-LD data (Schema.org) for superior search engine indexability.
*   **Performance Focused** Deployed as a static site for instantaneous load times and secure delivery.
*   **No Framework Overhead** Engineered completely from scratch using semantic HTML5, CSS3, and JavaScript, demonstrating strong foundational web development skills without reliance on bloated frameworks.

## Local Setup

To run this project locally on your machine, simply follow these steps

1.  Clone this repository `git clone https://github.com/Yass5002/portfolio.git`
2.  Navigate to the project directory `cd portfolio`
3.  Open `index.html` in your preferred web browser or serve it using a local development server (like VS Code Live Server) to prevent any CORS issues with the GitHub API fetch.
